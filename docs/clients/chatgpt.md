# ChatGPT

ChatGPT reaches AI VAT Number Validation through **Developer Mode**, currently in beta. It requires a **paid** plan (Plus, Pro, Business, Enterprise, or Edu), not the Free plan. On Business and Enterprise, an admin must enable Developer Mode for the workspace before you can add a connector.

## Steps

1. Go to **Settings → Connectors → Advanced → Developer mode** and enable it.
2. Add the MCP URL: `https://mcp-vat.iwebdevelopment.com`
3. Sign up when prompted: your email address and the KVK number of your own organization. You get a sign-in link by email.

See the [compatibility matrix](https://github.com/iwebdevnl/ai-vat-number-validation#client-compatibility) (last verified 2026-07).
